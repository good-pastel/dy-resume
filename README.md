## 🌸 About

This repository contains the source code for my personal digital resume, designed to provide recruiters, hiring managers, and collaborators with a concise overview of my professional background.

Rather than using a traditional PDF, this website presents my experience in a clean, responsive, and interactive format, making it easier to explore my skills, work history, education, and career journey across different devices.

🔗 **Live Website:**
https://good-pastel.github.io/dy-resume/

## 💡 Why an Online Resume?

Compared to a traditional resume, an online version offers several advantages:

- Always up to date
- Easy to share anywhere
- Mobile friendly
- Interactive experience
- Better integration with portfolio projects
- Accessible without downloading files
